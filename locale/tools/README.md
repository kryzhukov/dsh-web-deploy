Русский языковой пакет DSH — инструменты
========================================

Готовый пакет лежит здесь:

  %USERPROFILE%\.dsh\profiles\web\locale-ru\

В node_modules профиля на него указывает junction
node_modules\dsh-locale-ru, а в package.json профиля он объявлен как
"dsh-locale-ru": "file:locale-ru" — это защищает пакет от prune при
операциях pnpm/Plugin Manager.

А эти файлы — исходники для его обновления:

  _ru_dicts_en.json   — английские словари, извлечённые из клиентских
                        бандлов DSH (namespace -> key -> English)
  _ru_cache.json      — кэш переводов English -> Russian
  _build-dicts2.cjs   — извлекает словари из установленного DSH
  _translate-ru.cjs   — переводит только новые строки (Google Translate)
  _gen-client.cjs     — собирает lib/client.js языкового пакета

Порядок обновления после установки новой версии DSH
---------------------------------------------------
1. Проверьте путь к DSH в _build-dicts2.cjs (константа root). Обычно это
   %LOCALAPPDATA%\npm-cache\_npx\<hash>\node_modules\@deepseek-ai
2. Пересобрать английские словари:

     cd %USERPROFILE%\.dsh\ru-locale-tools
     node _build-dicts2.cjs

3. Доперевести новые строки (уже переведённые берутся из кэша):

     node _translate-ru.cjs

4. Пересобрать пакет:

     node _gen-client.cjs

5. Заставить DSH перечитать профиль — добавить/изменить любой комментарий
   в %USERPROFILE%\.dsh\profiles\web\cordis.patch.yml. HMR пересоберёт
   граф плагинов, и открытая страница подхватит новую ревизию бандла.
   Если страница не обновилась — перезагрузить её в браузере.

Правки перевода
---------------
- Удачные/неудачные переводы удобно править в _ru_cache.json по английскому
  оригиналу, затем запустить _gen-client.cjs.
- Самые заметные подписи (кнопки, режимы, темы) продублированы в объекте
  overrides в _gen-client.cjs — они имеют приоритет над кэшем.
- Строки с плейсхолдерами {name} проверяются: если Google меняет их,
  перевод делается через временные токены. Строки с ICU plural
  ({count, plural, ...}) не переводятся и остаются на английском.

Ограничения
-----------
- Перевод машинный, без контекста. Редкие технические описания могут звучать
  коряво; ключевые экраны вычитаны вручную.
- Часть строк DSH жёстко зашита в клиентские бандлы без словарей
  (например, "Open voice input setup", названия уровней reasoning "High").
  Они остаются английскими.
- Пакет лежит в profiles\web\locale-ru, подключён junction'ом в node_modules
  и объявлен зависимостью file:locale-ru. Если pnpm пересоздаст node_modules,
  он восстановит ссылку из package.json; если нет — создайте junction вручную.
